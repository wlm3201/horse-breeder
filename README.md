# Horse Breeder 自动养马

[English](README.en.md) | 简体中文

Minecraft Fabric 客户端模组，自动驯服、繁殖、催熟、淘汰马匹，以迭代出速度、跳跃、生命及毛色、花纹达到目标的马匹。

## 使用

1. 准备 10×10 围栏场地，两匹马，足量胡萝卜、金萝卜和斧头。
2. ModMenu 内设置目标数量、目标三维与目标花色。
3. 按下快捷键 **B** 开始自动养马。

### 基础配置

| 配置项     | 说明                                    |
| ---------- | --------------------------------------- |
| 启用       | 总开关，与快捷键相同                    |
| 催熟幼马   | 给幼马喂胡萝卜加速长大                  |
| 最大马数   | 马圈同时存在的马数，超过后将开始淘汰    |
| 目标匹数   | 需达到标准的马数量，达到后停止培育      |
| 检测范围   | 仅计入和处理该范围内马                  |
| 目标速度   | 目标马最低速度，格/秒                   |
| 目标跳跃   | 目标马最低跳跃高度，格                  |
| 目标生命   | 目标马最低生命值，半心                  |
| 喂食驯服   | 喂胡萝卜加速驯服                        |
| 目标温顺度 | 喂食达到该temper值后开始驯服            |
| 自动补货   | 自动从容器取物补充背包                  |
| 金萝卜容器 | 手持金萝卜潜行左键标记容器，格式`x y z` |
| 胡萝卜容器 | 手持胡萝卜潜行左键标记容器，格式`x y z` |
| 花色筛选   | 每花色养出[目标匹数]，不选则无花色限制  |

### 高级配置

| 配置项     | 说明                     |
| ---------- | ------------------------ |
| 手长       | 最大交互距离             |
| 配对保守度 | 亲代近似程度             |
| 自动进食   | 饥饿值不满时吃金萝卜恢复 |
| 自动移动   | 目标超出手长时自动走过去 |
| 保护命名马 | 命名的马将不会被淘汰     |
| 暴击       | 攻击前跳跃以暴击         |
| 忽略挤压   | 忽略马的碰撞挤压         |
| 丢弃皮革   | 自动丢弃背包中皮革       |
| 丢弃朝向   | 向此朝向丢弃             |
| 显示 HUD   | 是否绘制 HUD             |
| 发光标记   | 为不同状态的马添加描边   |
| HUD 横坐标 | 距屏幕左侧的像素         |
| HUD 纵坐标 | 距屏幕上边的像素         |
| 诊断日志   | 排查问题时打开           |

### 发光标记颜色

| 颜色 | 含义             |
| ---- | ---------------- |
| 黄   | 操作对象         |
| 紫红 | 配对中           |
| 金   | 已达标           |
| 紫   | 配对候选         |
| 橙   | 淘汰候选         |
| 青   | 幼马             |
| 绿   | 可繁殖           |
| 红   | 冷却中           |
| 灰   | 未驯服/受伤/被骑 |

## HUD

```
养马 [开]  数据：精确
上限 20  成年 8  可繁殖 1  冷却 4  求爱 2  未驯服 1  幼马 2
```

**精确**：单人直读集成服务端；**推算**：多人游戏靠喂食与事件推断
